# Dilasa Yaman Portfolio

Personal portfolio website for Dilasa Yaman, built with React, Vite, JavaScript, React Router, and modular CSS.

## Run Locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

The production build outputs to `dist/`.

## Project Structure

- `src/components`: reusable navigation, footer, buttons, headings, project cards, placeholders, and skill groups.
- `src/pages`: route-level pages for Home, About, Projects, project case studies, Resume, Contact, Book, and 404.
- `src/data/siteData.js`: centralized profile, links, project, skills, experience, achievement, service, and values content.
- `src/styles/global.css`: design system tokens and responsive styles.
- `public/documents`: static downloadable documents.
- `public/images`: placeholder image assets and replacement notes.
